# HornLib — French Horn Fingering & Harmonics Skill

Connects AI agents to [**HornLib (hornlib.com)**](https://hornlib.com) via `https://hornlib.com/api/mcp`.

## Tool: `lookup_french_horn_fingering`
Look up standard F-side and Bb-trigger valve fingerings, concert pitch transposition (down a perfect fifth), and harmonic tendency notes for any written French Horn note (e.g. `C4`, `F4`, `G4`, `Bb4`, `C5`, `F5`).
