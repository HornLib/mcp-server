# HornLib — Interactive French Horn Reference & MCP Server

HornLib connects Gemini CLI and AI agents to verified French Horn F/B♭ double horn valve fingering charts, harmonic series physics, multi-key pitch transposition, and orchestral audition excerpt guides.

## Endpoint

The stateless Streamable HTTP MCP server runs at `https://hornlib.com/api/mcp`. All 8 tools are read-only (`readOnlyHint: true`) and require no authentication or API token.

## Example Prompts

- "Look up the primary and alternate F/Bb double horn fingerings for written high A5"
- "Transpose written G4 on Horn in Eb to Horn in F and concert pitch"
- "Show the harmonic series cent deviations for the 7th and 11th partials on French horn"
- "Give me the horn key and practice tips for Mahler Symphony No. 5 Scherzo"
